DEPLOYMENT INSTRUCTIONS
================================================================================

OPTION 1: RAILWAY (RECOMMENDED - 5 MINUTES)
--------------------------------------------

1. Go to: https://railway.app
2. Sign up with GitHub
3. Click: "New Project" → "Deploy from GitHub repo"
4. Select: Your FoodBridge repository
5. Add environment variable:
   - SECRET_KEY = [generate random string]
6. Click: "Deploy"
7. Wait 2-3 minutes
8. Your app is live at: https://yourapp-name.railway.app

OPTION 2: RENDER (ALTERNATIVE - 15 MINUTES)
---------------------------------------------

1. Go to: https://render.com
2. Sign up with GitHub
3. Click: "New" → "Web Service"
4. Select: Your FoodBridge repository
5. Configure:
   - Runtime: Python 3.11
   - Build Command: pip install -r requirements.txt && python ml/model.py
   - Start Command: gunicorn -w 4 -b 0.0.0.0:$PORT app:app
6. Create PostgreSQL database
7. Copy database connection URL
8. Add environment variables:
   - DATABASE_URL = [paste PostgreSQL URL]
   - SECRET_KEY = [generate random string]
9. Click: "Create Web Service"
10. Wait 3-5 minutes
11. Your app is live at: https://yourapp-name.onrender.com
